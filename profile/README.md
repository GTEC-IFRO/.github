## 🚀 Frentes de Trabalho & Projetos

Os repositórios desta organização estão distribuídos nos seguintes eixos:

### 1. 📡 Redes, Telemetria & Monitoramento
* Coleta, ingestão e análise de dados em tempo real para monitoramento ambiental e territorial.
* Desenvolvimento de pipelines de telemetria, sensores e integração com bancos de dados analíticos.

### 2. 🖥️ Infraestrutura & DevOps
* Automação de ambientes virtualizados, orquestração de contêineres e clusters de alta disponibilidade.
* Políticas de deploy contínuo (CI/CD), gestão de storage distribuído e regras de borda/firewall.
* Priorização de soluções *Free and Open-Source Software* (FOSS).

### 3. 🔬 Pesquisa Aplicada & Inovação
* Ferramentas de apoio à bioeconomia, modelagem de dados territoriais e sustentabilidade.
* Provas de Conceito (PoCs) e sistemas experimentais desenvolvidos com estudantes e pesquisadores.

### 4. 📚 Ensino & Extensão
* Templates de laboratório, roteiros práticos de redes e sistemas operacionais.
* Repositórios de suporte para turmas e projetos acadêmicos aplicados.

## 🤝 Governança e Diretrizes de Colaboração

Todos os membros da equipe e colaboradores externos devem seguir as diretrizes estabelecidas:

1. **Branching Strategy:**
   * A branch `main` reflete o código testado e estável. Commits diretos são bloqueados via regras de proteção.
   * Crie branches no formato `feat/nome`, `fix/nome` ou `infra/nome`.
2. **Pull Requests:**
   * Todo PR deve utilizar o [Template de Pull Request](PULL_REQUEST_TEMPLATE.md) padrão.
   * É obrigatória a aprovação de ao menos um revisor e a validação de rotinas de CI antes do merge.
3. **Segurança de Código:**
   * **Nunca** suba segredos, chaves de API, credenciais de banco ou arquivos `.env` para nenhum repositório.
   * Vulnerabilidades devem ser reportadas conforme nosso [SECURITY.md](SECURITY.md).
4. **Padronização:**
   * Para relatar falhas ou propor melhorias, use os formulários em `.github/ISSUE_TEMPLATE/`.
   * Consulte o guia detalhado em [CONTRIBUTING.md](CONTRIBUTING.md).
